# Data-Visualization

Repositorio dedicado a la **visualización de datos** y creación de **dashboards interactivos**, utilizando herramientas como Python (librerías de visualización) y Power BI. El objetivo es transformar datos en insights claros y accionables.

## 📂 Contenido (esperado)

- **Notebooks de Python** con visualizaciones usando `matplotlib`, `seaborn`, `plotly` y `pandas`.
- **Dashboards en Power BI** (archivos `.pbix`) con ejemplos de KPIs, filtros y narrativa visual.
- **Conjuntos de datos** de muestra (si son pequeños o de acceso público).

## 🛠️ Herramientas y librerías

- **Python 3.7+** → Jupyter Notebook, pandas, matplotlib, seaborn, plotly.
- **Power BI Desktop** → para dashboards avanzados.
- **SQL** (ocasionalmente) para consultas a fuentes de datos.
